# Introduction

Alauda Data Services Search Engine E1 deploys and manages OpenSearch® clusters on Alauda
Container Platform. It is built from source on the open-source
[OpenSearch Kubernetes Operator](https://github.com/opensearch-project/opensearch-k8s-operator)
project, version 3.0, and is delivered as an OLM package for Alauda Container Platform.

## Supported engine versions

| OpenSearch version | Notes |
|---|---|
| 3.8.0 | Default |
