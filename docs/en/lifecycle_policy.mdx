# Lifecycle Policy

## Version Lifecycle Timeline

Below is the lifecycle schedule for released versions of the Alauda Data Services Search Engine E1:

| Alauda Data Services Search Engine E1 Version | Release Date | End of Support |
|:--------------------:|:------------:|:--------------------:|
| v3.0.x               | 2026-10-16   | Supported until 2028-04-16 (18 months from v3.0.0-acp.3 GA on 2026-10-16) |

## Release Policy

The Alauda Data Services Search Engine E1 follows this lifecycle:

- **Support window**: each minor version (for example, v3.0.x) receives Full Support followed by Maintenance for **18 months from its general availability (GA) date**. Patch releases within a minor version do not extend its support window. For v3.0.x, the window is counted from the v3.0.0-acp.3 GA on 2026-10-16.
- **Patch releases**: security (CVE) and bug fixes are rolled up into patch releases. Critical fixes are released on an expedited schedule.
- **Long-life releases**: minor versions designated as long-life receive backported security (CVE) and urgent bug fixes for up to **36 months** from GA, without requiring an upgrade. v3.0.x is not currently designated as a long-life release.
- **Update delivery**: updates are delivered through Alauda Cloud (AC) channels and are applied automatically or after approval by a cluster administrator.

Operator 2.8.0 is a separate product line and is not covered by this table. To move from it to this operator, see [Upgrade](./upgrade.mdx).

## Maintenance Policy

Alauda provides maintenance support for the Alauda Data Services Search Engine E1 based on the lifecycle described above.

During the support period of each version, Alauda provides the following services:

- **Security Updates**: Regular patches and updates in line with Alauda security standards.
- **Bug Fixes**: Timely fixes for critical and major issues, aligned with upstream OpenSearch and OpenSearch Kubernetes Operator community fixes.
- **Upgrade Assistance**: Guidance and support for smooth upgrades between Alauda Data Services Search Engine E1 versions.
- **Regular Maintenance**: Periodic updates to ensure the operator remains stable and compatible with the Kubernetes ecosystem.
